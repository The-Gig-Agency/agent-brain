# echelon — v0.1 Debugging Core

## Purpose

This is the narrowed decision gate for Echelon.

Do not ask:

- can Echelon become a broad cognition platform?
- can it generalize to every reasoning domain?
- can it support many orchestration patterns?

Ask only:

- can adaptive search-policy selection improve debugging search behavior?

## Scope

In scope:

- coding and debugging tasks only
- 4 regimes only
  - `explore`
  - `prune`
  - `compound`
  - `check`
- repeated failed-path suppression
- search adaptation after bad evidence
- convergence and cost metrics
- local benchmark runner

Out of scope for v0.1:

- generalized cognition platform
- human decision routing
- broad orchestration framework
- multi-agent ecosystems
- ontology expansion
- configurable graph DSLs
- hosted service or UI

## Core thesis

Most agent failures in debugging are not answer failures first.
They are search failures:

- repeated retries on the same dead path
- premature convergence
- shallow decomposition loops
- bad transition timing

v0.1 exists to test whether Echelon can reduce those failures.

## Baselines

v0.1 compares routed policy against:

- `naive_retry`
- `always_compound`
- `fixed_heuristic`

These are enough for the first decision gate.

## Metrics

Primary metrics:

- repeated failed-path count
- retries before success
- total search cost
- success rate

Secondary metrics:

- transition count
- transition timing quality
- dead-end persistence
- regime hysteresis
- false convergence rate

## Go / no-go rule

v0.1 is promising if:

- routed policy is not worse than `fixed_heuristic` on success rate
- routed policy beats `naive_retry` on repeated failed-path suppression
- routed policy beats `naive_retry` on total search cost
- routed policy beats `always_compound` on repeated failed-path suppression

If that is not true, do not widen scope.

## Interpretation

v0.1 is not trying to prove:

- universal reasoning superiority

It is trying to prove:

- retry suppression plus adaptive search policy is a real wedge

That is enough for the next stage.
